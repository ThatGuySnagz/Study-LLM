# Privacy

This is a local-first notice for a template the person runs on their own machine. It is not a privacy policy for a hosted service.

## What this is

Study LLM is a template the person runs on their own machine. There is no account. There is no service operated by the template.

## Notes

The template does not collect notes. It does not keep a copy of model requests.

## Local files

Materials, extracted text, decks, and progress stay in local folders unless the person copies them somewhere else.

## AI calls

Content leaves the machine only in a request to the model the person configures. That can be their API, or a local model. That provider's terms apply to the call. The template does not store the request.

## Teachers and student work

A teacher who sends student work to a commercial model is responsible for school rules, including FERPA for US schools. This notice does not claim the template is FERPA-compliant. This is not legal advice.

## Sharing

Copying a deck file is the person's own act. The template has no server that receives it.
